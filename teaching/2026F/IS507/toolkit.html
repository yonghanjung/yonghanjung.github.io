Before any tool

The tool changes; this procedure does not. Do these in order, every time.

  1. Hold out a test set firstSplit before you look. For time series, the test set is the last stretch of time, never a random sample.
  2. Measure a baselineMean, majority class, last value, same season last year, or a linear model. Write the number down.
  3. Choose settings on validationUse cross-validation or a validation split to pick models and settings. The test set is used once, at the end.
  4. Compare training and validation errorA large gap means overfitting. Both high means the model is too simple or the features are weak.
  5. If they tie, keep the simpler oneA foundation model has to beat the baseline by more than the noise to earn its cost, license, and download.
