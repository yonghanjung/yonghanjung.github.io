Page B sells 1.5 points more. Real, or luck?

1Hypotheses

Hypotheses are about the population, not about our sample

θA = the true buying rate of page A, over all future visitors
θB = the same for page B
These are population parameters. We never see them; we only see 4,000 visitors per page.
H0: θB = θAB is no different
H1: θB ≠ θAB is different

✗ Not “H0: 10.0% = 11.5%”. Those are sample numbers, and we already know they differ.

2Statistic

Estimate each parameter, then compare

1 = bought, 0 = did not. 4,000 rows per page.
θ̂A = mean of column A = 400 / 4000 = 0.100
θ̂B = mean of column B = 460 / 4000 = 0.115
D = θ̂B − θ̂A = 0.015 = +1.5 points
D is our statistic: one number, computed from the sample, that estimates θB − θA. A new sample would give a different D.
3H0 distribution

If H0 is true, how does D move from sample to sample?

Even when nothing changed, D is not 0. Draw one day of 4,000 + 4,000 visitors with the same rate for both pages:

The CLT gives the whole shape. Under H0 both pages share one rate; pool them:
p̂ = 860 / 8000 = 0.1075
SE0 = √( p̂(1−p̂)(1/4000 + 1/4000) ) = 0.69 points
Under H0: D ~ N(0, 0.69²), so z = D / SE0 ~ N(0, 1)

4H1 distribution

If B truly adds δ points, how does D move?

H1 is not one world but many: one for each true gain δ. Pick one. Its bell has the same width, shifted to δ.

Under H1 with gain δ: D ~ N(δ, SE²)
In a real plan δ is chosen before the data: the smallest gain that matters. Here δ = 1.5.
5α and decision

α: how often we accept a false alarm

Definition α = P( reject H0 | H0 true ) In words: if B is really no better, how often our rule still says “B is better”. The false alarm rate of the rule. We fix it before the data. α = 0.05: about 5 false alarms in 100 tests of a useless page. Common misreadings
  • ✗ “α is the chance that H0 is true.” α assumes H0 is true; it never asks whether it is.
  • ✗ “We rejected, so it is a false alarm with chance 5%.” That is P(H0 true | reject). It depends on how many ideas really work: in ⑥(c) it is 44%.
  • ✗ “α is the p-value.” α is fixed before the data; the p-value is computed from the data. We compare the two.
α sets the cutoff on the H0 bell (rust). Decide: reject H0 if |z| ≥ cutoff, i.e. if p ≤ α.

6Power

Power: how often we catch a real gain

Definition power(δ) = P( reject H0 | θB − θA = δ ) In words: if B really adds δ points, how often our rule says “B is better”. The catch rate. Miss: β = 1 − power. Built from ④ and ⑤: the share of the H1 bell beyond the cutoff that α set on the H0 bell. Computed before the data, from δ, n, and α. Common misreadings
  • ✗ “Power is the chance that H1 is true.” Power assumes the gain is δ; it never asks whether it is.
  • ✗ “Power says how strongly our data support H1.” Power never looks at our data: it is 0.58 whether we see D = +2.0 or D = +0.2 (table below).
  • ✗ “A test has one power.” Power changes with δ, with the visitors n, and with α. Move the sliders.
  • ✗ “Not significant, so there is no gain.” At δ = 1.0 with 4,000 per page, power is 0.30: a real gain is missed 7 times in 10.
