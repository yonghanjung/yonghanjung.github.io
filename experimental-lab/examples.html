CausalEngine

Examples & support

Choose a causal structure and enter unique variable names in each role. Identify checks the graph without data; Estimate uses your mapped CSV or optional Random Data on your device.

No unmeasured confounding

Enter A, covariates C1/C2/C3, and outcomes Y1/Y2/Y3. The template connects observed covariates to actions and outcomes. Identification and data-only estimation are checked separately for each outcome. Match every observed variable to a numeric CSV column, or try Random Data.

Inspect and reproduce an estimate

A compatible baseline graph with a scalar or ordered binary-cluster treatment offers AIPW, Outcome Regression (Plug-in), and IPW. Choose ATE to compare two complete assignments or APO for one interventional mean. AIPW retains XGBoost outcome predictions and scalar fitted-outcome balancing weights. Outcome Regression uses only XGBoost outcome predictions. IPW fits an actual XGBoost classifier for the whole observed treatment tuple, then averages raw inverse-probability-weighted outcomes; no outcome model or balancing-weight solver is fitted. The requested probability guard is 1e-6, without clipping or held-out renormalization. Details and Calculation code record the actual query, nuisance fits, classifier class map, original retained columns, folds and diagnostics. These fitted probabilities do not prove positivity, and no failed fit silently switches methods.

For a treatment cluster, enter A(a1, a2) in Treatment and keep the two binary source columns in that order. Set each member’s treatment value; ATE also has member-specific reference values. The causal graph retains one logical A. Switching ATE/APO, values or method reuses the retained data; Random Data still requires Generate Data after model, dimension, seed or record changes.

Front-door

Use a separate Mediators field, such as M, between A and Y. Optional baseline covariates stay separate. The generated template has a hidden common cause of actions and outcomes; a conditional Front-door query may be supported. A hidden root needs no CSV column. Estimation can return a coverage warning.

No unmeasured confounding -- Sequential

Add or remove time points and enter covariates, treatments, and outcomes at each time. Identify each outcome, then estimate the action sequence from the same uploaded or generated rows. Full history connects earlier variables to all later times. Markovian order limits direct arrows by the displayed Time ID lag; blank or removed gaps still count. Arrows remain editable assumptions.

Random treatment and outcome configurations

Start with plain Treatment A, Covariates X, and Outcomes Y. Open Random Data, set A dimension 2, X dimension 2, Records 5,000, Model seed 7 and Data seed 5. Choose Linear outcome and Generate Data. Set the member assignment to [1, 0] and its ATE reference to [0, 0]; APO instead uses just the first assignment. Compare the three estimators on the same records. A dimension supports 1–4 binary members; X supports 1–50 coordinates. Declared member names retain their order.

Choose Quadratic outcome or Bounded outcome (logistic link), then Generate Data again to try another outcome mechanism. The picker selects normal noise. Quadratic adds parent squares rather than interactions, and vector mechanisms may mix noise. A new configuration invalidates old records; query or method changes alone do not. Click A or X to expand the member view. Head toggles the preview and Download CSV saves the complete snapshot without regeneration.

Upload a covariate cluster

Download the 512-row example CSV. Use Treatment A, Covariates X (x1, …, x25), and Outcomes Y. Update the graph, then upload the file. If your browser does not open its file dialog, use Example CSV → Load example or Other ways to load CSV → drop/paste. Click X to expand or collapse its member view. The logical graph stays unchanged, and uploaded data have no supplied ground truth.

Benchmark datasets

Open Estimate → Benchmarks for IHDP, LaLonde, and ACIC. Inspect the specific release and source before using it. Select a dataset, then choose Download CSV or Estimate. Estimate preserves the chosen graph, variable names, arrows, and positions. In a compatible treatment–baseline–outcome graph, all released covariates bind to the existing baseline node as one cluster. Open Data columns to inspect every member. Structures requiring unavailable mediator or time-specific bindings are reported without replacing the graph. The working CSV includes factual observations, not counterfactual answers. Head and Download CSV reuse the loaded records.

Not implemented

IV with Monotonicity: requires an instrument and additional assumptions; its usual target is the effect among compliers, not the population average effect. Monotonicity cannot be checked from the graph alone.

IV bounding: returns a range of possible effects and requires a separate bounding procedure.

Difference-in-Differences: a study design comparing changes over time, with assumptions such as parallel trends.

Synthetic Control: a comparison-over-time design using a weighted donor group. A graph alone does not establish its validity.

These are not active calculation options. A known answer from a simulated model does not make an otherwise unidentified effect identifiable from observed data.
