CausalEngine

Code & installation

CausalEngine runs on your own device. Choose the browser app or install the Python package locally.

Use the browser app

Calculations run in a worker in your browser, using your device’s processor and memory. No local Python installation is needed. The first run needs internet access to download the Pyodide runtime and numerical libraries from jsDelivr.

Install on your computer

Use Python 3.12, the tested version. Download the wheel above and open a terminal in the folder containing it.

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install ./causalengine-0.1.0-py3-none-any.whl
python -c "import causalengine; print(causalengine.__version__)"

On Windows, create the environment with py -3.12 -m venv .venv, then activate it with .venv\Scripts\Activate.ps1 in PowerShell. See the full guide for alternatives.

The package installs its NumPy, SciPy, pandas, and NetworkX requirements. This local release is supplied as downloads; use the downloaded wheel rather than an unqualified package-name install.

Run a complete example

python -m causalengine demo
python -m causalengine demo --rows 2048 --data-seed 5

The native Python example generates a simulated class with a binary action and compares setting A to 1 versus 0. Read its estimate, model reference, and diagnostic messages. These are simulated results.

Use it from Python

from causalengine.demo import run_demo

result = run_demo(rows=512, data_seed=5)
print(result["comparison"]["data_estimate"])
print(result["comparison"]["scm_reference"])

Serve the app locally

python -m causalengine serve --port 8766

Open http://127.0.0.1:8766/ and keep the terminal running. Press Ctrl+C to stop it. This serves static files on your computer; calculations still run in the browser. The browser runtime uses CDN downloads, so this is not a fully offline bundle.
